# 开发日志 038：优惠券过期扫描

## 一、开发目标

本次继续完善普通购买优惠券闭环，补齐优惠券过期状态流转。

上一版已经支持：

```text
领取优惠券
普通购买下单使用优惠券
订单取消释放优惠券
```

但 `EXPIRED` 状态还没有真正落地。这样会导致已经过了 `valid_end_time` 的用户券仍然可能在查询时显示为 `UNUSED`。

本次目标：

```text
过期 UNUSED 用户券自动变为 EXPIRED
提供手动扫描接口
提供 Java 定时扫描任务
查询我的券之前先做当前用户的懒过期刷新
过期券不能用于普通下单
```

## 二、业务规则

只扫描用户券，不修改优惠券模板。

扫描条件：

```text
coupon_status = UNUSED
valid_end_time < now
```

扫描后的字段变化：

```text
coupon_status = EXPIRED
update_time = now
```

不处理：

```text
USED 券不改为 EXPIRED
已被订单使用的券保持 USED
订单取消释放回 UNUSED 后，如果已过期，后续扫描会改为 EXPIRED
```

## 三、实现内容

### 1. 领域服务

新增过期扫描结果模型：

```text
CouponExpireScanResult
```

新增领域方法：

```text
CouponService.expireUnusedCoupons(limit)
```

查询我的券前增加当前用户懒过期：

```text
CouponService.listUserCoupons(userId, couponStatus, limit)
```

也就是用户查券时，会先把当前用户已经过期的 `UNUSED` 券刷新为 `EXPIRED`，再返回查询结果。

涉及文件：

```text
food-trade-service/food-trade-domain/src/main/java/com/foodlife/trade/domain/order/coupon/model/CouponExpireScanResult.java
food-trade-service/food-trade-domain/src/main/java/com/foodlife/trade/domain/order/coupon/service/CouponService.java
```

### 2. 仓储能力

新增两个仓储方法：

```text
expireUnusedCoupons(now, limit)
expireUserUnusedCoupons(userId, now, limit)
```

第一个用于全局扫描，第二个用于当前用户查询前的懒刷新。

涉及文件：

```text
food-trade-service/food-trade-domain/src/main/java/com/foodlife/trade/domain/order/coupon/repository/ICouponRepository.java
food-trade-service/food-trade-infrastructure/src/main/java/com/foodlife/trade/infrastructure/repository/CouponRepository.java
```

### 3. HTTP 手动扫描接口

新增接口：

```http
POST /api/trade/coupons/expired/scan?limit=10
```

响应字段：

```text
scanTime
expireBefore
expiredCount
limit
```

涉及文件：

```text
food-trade-service/food-trade-api/src/main/java/com/foodlife/trade/api/dto/CouponExpireScanResponseDTO.java
food-trade-service/food-trade-trigger/src/main/java/com/foodlife/trade/trigger/http/CouponController.java
```

### 4. 定时扫描任务

新增定时任务：

```text
CouponExpireScanJob
```

配置：

```yaml
food:
  trade:
    coupon:
      expire-scan:
        enabled: true
        fixed-delay-ms: 60000
        limit: 500
```

涉及文件：

```text
food-trade-service/food-trade-trigger/src/main/java/com/foodlife/trade/trigger/job/CouponExpireScanJob.java
food-trade-service/food-trade-app/src/main/resources/application.yml
```

## 四、验证记录

### 1. 构建验证

```bash
mvn -pl food-trade-service/food-trade-app -am test -DskipTests
mvn -pl food-trade-service/food-trade-app -am package -DskipTests
```

结果：

```text
BUILD SUCCESS
```

### 2. 手动扫描验证

本地插入一张已过期 `UNUSED` 用户券：

```text
couponId = 5
couponStatus = UNUSED
validEndTime = 2026-08-12 21:32:16
```

调用：

```http
POST /api/trade/coupons/expired/scan?limit=10
```

返回：

```text
expiredCount = 1
limit = 10
```

数据库确认：

```text
couponId = 5
couponStatus = EXPIRED
```

### 3. 查询懒过期验证

本地插入一张已过期 `UNUSED` 用户券：

```text
couponId = 6
couponStatus = UNUSED
validEndTime = 2026-08-12 21:32:27
```

调用：

```http
GET /api/trade/coupons/mine?couponStatus=EXPIRED&limit=20
```

返回里包含：

```text
userCouponId = 6
couponStatus = EXPIRED
```

数据库确认：

```text
couponId = 6
couponStatus = EXPIRED
```

### 4. 过期券下单验证

使用 `userCouponId = 6` 下普通订单：

```http
POST /api/trade/orders/normal
```

返回：

```text
code = 400
message = coupon status can not use
```

说明过期券不能再被普通购买使用。

## 五、当前结论

优惠券已经具备基础生命周期：

```text
领取：UNUSED
使用：UNUSED -> USED
取消释放：USED -> UNUSED
过期扫描：UNUSED -> EXPIRED
```
