# 数据记录 - 拼团锁单数据

## 数据库

- 服务：`food-trade-service`
- 数据库：`food_trade_db`
- 本次新增表：`group_buy_activity`、`group_buy_order`、`group_buy_order_list`
- 订单主表仍使用：`dining_order`
- 订单明细表仍使用：`dining_order_item`

## 表职责

| 表 | 职责 |
| --- | --- |
| `group_buy_activity` | 记录某个美食套餐是否参加拼团、成团人数、用户参与限制、拼团价、活动库存和有效期 |
| `group_buy_order` | 记录一支拼团队伍，包含 `team_id`、目标人数、锁定人数、支付完成人数、队伍状态 |
| `group_buy_order_list` | 记录用户参与拼团的明细，关联用户、队伍、交易订单、活动和套餐 |
| `dining_order` | 统一交易订单主表，本次拼团订单的 `trade_type = GROUP_BUY` |
| `dining_order_item` | 统一交易订单明细，保存套餐交易快照 |

## 拼团锁单写入关系

1. 首次开团：创建 `group_buy_order`，生成新的 `team_id`，`lock_count = 1`。
2. 参与已有团：更新已有 `group_buy_order.lock_count = lock_count + 1`。
3. 创建交易订单：写入 `dining_order`，`trade_type = GROUP_BUY`，`order_status = WAIT_PAY`。
4. 创建订单明细：写入 `dining_order_item`，保存套餐名称、门店、封面、价格、使用规则快照。
5. 创建拼团明细：写入 `group_buy_order_list`，记录用户和队伍的锁单关系，`order_status = LOCKED`。
