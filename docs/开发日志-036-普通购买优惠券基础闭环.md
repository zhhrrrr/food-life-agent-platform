# 开发日志-036：普通购买优惠券基础闭环

## 一、开发目标

本次继续只做非 Agent 业务。

之前普通购买金额计算是：

```text
totalAmount = 套餐价格 * 数量
payAmount = totalAmount
```

本次新增平台优惠券基础闭环，让普通购买可以使用满减券：

```text
查券模板
领取优惠券
查看我的券
下单使用优惠券
订单落优惠金额
用户券状态变更为 USED
重复用券被拒绝
```

## 二、业务规则

当前只做基础满减券：

```text
coupon_type = FULL_REDUCTION
threshold_amount = 满减门槛
discount_amount = 优惠金额
```

用券规则：

```text
1. 用户必须登录
2. userCouponId 必须属于当前用户
3. 用户券状态必须是 UNUSED
4. 当前时间必须在有效期内
5. 订单总金额必须达到 threshold_amount
6. 下单成功后 user_coupon 状态变为 USED，并记录 used_order_id
7. 同一张券不能重复下单
```

## 四、新增接口

### 1. 查询可领取券模板

```http
GET /api/trade/coupons/templates?limit=10
```

### 2. 领取优惠券

```http
POST /api/trade/coupons/templates/{templateId}/receive
```

### 3. 查询我的券

```http
GET /api/trade/coupons/mine?couponStatus=UNUSED&limit=20
GET /api/trade/coupons/mine?couponStatus=USED&limit=20
```

### 4. 普通下单使用优惠券

```http
POST /api/trade/orders/normal
```

请求示例：

```json
{
  "packageId": 1,
  "quantity": 1,
  "userCouponId": 1
}
```

返回新增字段：

```text
totalAmount
discountAmount
payAmount
userCouponId
```
