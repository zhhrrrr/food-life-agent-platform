# 开发日志 037：订单取消释放优惠券

## 一、开发目标

本次继续完善普通购买闭环，补齐“订单取消后释放优惠券”的业务一致性。

上一版已经支持：

```text
领取优惠券
普通购买下单使用优惠券
订单记录 discountAmount、payAmount、userCouponId
用户券状态从 UNUSED 变为 USED
```

但订单取消时还需要把用户券释放回来，否则会出现：

```text
订单已经取消
库存已经释放
优惠券仍然被占用
```

本次补齐两条取消路径：

```text
用户主动取消普通订单
普通订单超时补偿取消
```

## 二、业务规则

只处理普通购买订单使用的优惠券。

当前规则：

```text
1. 订单必须属于当前登录用户
2. 只有 WAIT_PAY 状态订单可以取消
3. 订单取消成功后释放普通套餐库存
4. 如果订单使用了优惠券，则释放用户券
5. 释放用户券时必须匹配 userCouponId、userId、orderId、USED 状态
6. 释放后 user_coupon.coupon_status 回到 UNUSED
7. 释放后 user_coupon.used_order_id 和 user_coupon.use_time 清空
```

拼团、秒杀取消路径暂不处理优惠券，因为当前优惠券只接入了普通购买。

## 三、实现内容

### 1. 主动取消释放优惠券

入口：

```http
POST /api/trade/orders/{orderId}/cancel
```

普通订单取消成功后执行：

```text
更新订单 WAIT_PAY -> CANCELED
释放优惠券
发送普通套餐库存释放消息
返回取消结果
```

涉及文件：

```text
food-trade-service/food-trade-domain/src/main/java/com/foodlife/trade/domain/order/service/OrderDomainService.java
```

### 2. 超时取消释放优惠券

入口：

```http
POST /api/trade/normal/orders/timeout/cancel?timeoutMinutes=30&limit=20
```

补偿任务扫描超时未支付普通订单，取消成功后执行：

```text
更新订单 WAIT_PAY -> CANCELED
释放优惠券
发送普通套餐库存释放消息
记录 couponReleased 结果
```

涉及文件：

```text
food-trade-service/food-trade-domain/src/main/java/com/foodlife/trade/domain/order/normal/service/NormalOrderTimeoutCancelService.java
food-trade-service/food-trade-domain/src/main/java/com/foodlife/trade/domain/order/normal/model/NormalOrderTimeoutCancelDetail.java
food-trade-service/food-trade-api/src/main/java/com/foodlife/trade/api/dto/NormalOrderTimeoutCancelResponseDTO.java
food-trade-service/food-trade-trigger/src/main/java/com/foodlife/trade/trigger/http/NormalOrderTimeoutCancelController.java
```

### 3. 优惠券释放仓储修正

释放优惠券时不能只用实体对象把字段设为 null，因为 MyBatis-Plus 默认不会把 null 字段更新到数据库。

本次改成显式 `LambdaUpdateWrapper.set(..., null)`：

```text
coupon_status = UNUSED
used_order_id = NULL
use_time = NULL
update_time = now
```

同时使用这些条件保证幂等和归属正确：

```text
id = userCouponId
user_id = userId
used_order_id = orderId
coupon_status = USED
```

涉及文件：

```text
food-trade-service/food-trade-infrastructure/src/main/java/com/foodlife/trade/infrastructure/repository/CouponRepository.java
food-trade-service/food-trade-domain/src/main/java/com/foodlife/trade/domain/order/coupon/service/CouponService.java
```

## 六、当前结论

普通购买的“下单占券 -> 取消释放券 -> 库存释放”已经闭环。

现在普通购买取消后的资源回滚包括：

```text
订单状态回滚到取消态
优惠券回到可使用态
普通套餐库存销量通过本地消息释放
```

后续可以继续做：

```text
优惠券过期扫描
优惠券适用店铺/套餐范围
退款后优惠券是否退回的策略
支付超时关闭支付单后的统一补偿
```
