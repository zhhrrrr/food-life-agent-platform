# 开发日志 004：用户登录接口联调验证

## 一、本次验证目标

本次验证目标是实际跑通 `food-user-service` 的完整登录链路。

验证链路：

```text
MySQL 可用
Redis 可用
启动 food-user-service
调用 /api/user/code
调用 /api/user/login
检查 MySQL 用户数据

携带 Token 调用 /api/user/me
调用 /api/user/logout
再次调用 /api/user/me 验证 Token 失效
```

## 十、Token 失效验证


```text

```

## 十一、本次验证结论

本次用户登录链路验证通过。

已经确认：

```text
1. MySQL 本地连接正常
2. Redis 本地连接正常
3. food-user-service 可启动
4. 验证码可写入 Redis
5. 登录可自动创建用户
6. 用户主数据可写入 MySQL
7. Token 可写入 Redis Hash
8. /api/user/me 可通过 Token 获取当前用户
9. /api/user/logout 可删除 Token
10. 登出后再次访问 /api/user/me 会返回 401
```
