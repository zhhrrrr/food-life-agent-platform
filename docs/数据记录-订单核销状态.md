# 数据记录-订单核销状态

## 关联数据库

```text
food_trade_db
```

## 关联表

```text
dining_order
```

## 新增字段

```text
use_time DATETIME DEFAULT NULL COMMENT 'package use time'
```

含义：

```text
美食套餐订单到店核销/使用完成的时间。
```

## 新增订单状态

```text
USED
```

含义：

```text
订单已经完成套餐核销。
```

## 当前状态流转

```text
下单：null -> WAIT_PAY
取消：WAIT_PAY -> CANCELED
模拟支付：WAIT_PAY -> PAID
模拟核销：PAID -> USED
重复核销：USED -> USED，返回 repeat
模拟退款：PAID -> REFUNDED
```

## 模拟核销接口

```text
POST /api/trade/orders/{orderId}/use/mock
```

当前执行成功后更新：

```text
dining_order.order_status = USED
dining_order.use_time = 当前时间
dining_order.update_time = 当前时间
```

更新条件：

```text
id = orderId
order_status = PAID
```

这个条件用于保证：

```text
只有已支付订单可以核销
重复核销返回 repeat 行为
待支付订单不能核销
已取消订单不能核销
已退款订单不能核销
并发核销只有一次能成功
```

## 本地库变更 SQL

已有本地库需要执行：

```sql
ALTER TABLE food_trade_db.dining_order
  ADD COLUMN use_time DATETIME DEFAULT NULL COMMENT 'package use time'
  AFTER order_status;
```
