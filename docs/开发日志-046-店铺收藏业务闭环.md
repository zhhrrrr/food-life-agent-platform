# 开发日志 046：店铺收藏业务闭环

## 一、本次目标

继续完善微服务模块前的非 Agent 业务能力。

本次在 `food-business-service` 新增店铺收藏闭环：

1. 登录用户收藏店铺。
2. 登录用户取消收藏店铺。
3. 查询当前用户是否收藏某店铺。
4. 查询我的收藏店铺列表。
5. 收藏和取消收藏都保持幂等。
6. 收藏记录软取消，不做物理删除，后续可作为用户偏好数据。

## 二、服务边界

店铺收藏放在 `food-business-service`。

原因：

- 收藏对象是店铺，属于店铺业务域。
- 它不需要查询订单，不依赖 trade-service。
- 用户身份继续复用 `food-auth-starter` 的黑马点评登录态。
- 当前不新增微服务，继续保持少服务拆分。

## 三、接口设计

收藏相关接口全部放在：

```text
/api/favorites/shops/**
```

没有放在 `/api/shop/**` 下，是因为当前 `business-service` 把 `/api/shop/**` 配成公开查询路径。

收藏是用户私有行为，必须走登录拦截。

### 1. 收藏店铺

```http
POST /api/favorites/shops/{shopId}
authorization: {token}
```

成功响应：

```json
{
  "code": "0000",
  "message": "success",
  "data": {
    "favoriteId": 1,
    "userId": 45,
    "shopId": 1,
    "favorite": true,
    "createTime": "2026-08-29T16:33:00",
    "updateTime": "2026-08-29T16:33:00"
  }
}
```

重复收藏返回同一条收藏关系，仍为成功。

### 2. 取消收藏

```http
DELETE /api/favorites/shops/{shopId}
authorization: {token}
```

成功响应：

```json
{
  "code": "0000",
  "message": "success",
  "data": {
    "favoriteId": 1,
    "userId": 45,
    "shopId": 1,
    "favorite": false
  }
}
```

重复取消收藏仍返回成功，保证前端重复点击不会产生异常。

### 3. 查询收藏状态

```http
GET /api/favorites/shops/{shopId}/status
authorization: {token}
```

### 4. 我的收藏店铺列表

```http
GET /api/favorites/shops?pageSize=5
authorization: {token}
```

## 四、业务流程

### 1. 收藏

```text
用户携带 token 请求 business-service
  -> auth-starter 校验登录态
  -> UserHolder 获取 userId
  -> 校验 shopId
  -> 查询 shop，确认店铺存在
  -> 查询 shop_favorite 是否已有 userId + shopId 记录
  -> 不存在则插入 favorite_status=1
  -> 已存在但状态为 0，则恢复为 1
  -> 已存在且状态为 1，直接返回
```

### 2. 取消收藏

```text
用户携带 token 请求 business-service
  -> 查询 userId + shopId 收藏记录
  -> 不存在时直接返回 favorite=false
  -> 已存在时更新 favorite_status=0
```

### 3. 收藏列表

```text
按 userId + favorite_status=1 查询收藏关系
  -> 按 id 倒序游标分页
  -> 根据 shopId 查询店铺快照
  -> 只返回仍然在线的店铺
```

## 六、数据设计

新增表：`food_business_db.shop_favorite`

字段：

| 字段 | 说明 |
| --- | --- |
| `id` | 收藏关系 ID |
| `user_id` | 用户 ID |
| `shop_id` | 店铺 ID |
| `favorite_status` | 1 收藏，0 取消 |
| `create_time` | 创建时间 |
| `update_time` | 更新时间 |

核心索引：

| 索引 | 作用 |
| --- | --- |
| `uk_user_shop(user_id,shop_id)` | 保证一个用户对一个店铺只有一条收藏关系 |
| `idx_user_status_id(user_id,favorite_status,id)` | 我的收藏列表游标分页 |
| `idx_shop_id(shop_id)` | 后续统计店铺收藏人数预留 |
