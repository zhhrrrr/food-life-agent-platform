
这样 Sentinel Dashboard 里的应用名稳定，且 command 端口不会互相抢占。

### Feign 熔断配置

本次验证中曾尝试开启旧配置：

```yaml
feign:
  sentinel:
    enabled: true
```

结果 business-service 启动失败，核心错误是：

```text
Method TradeOrderClient#queryOrderDetail(Long) not annotated with HTTP method type
Class TradeOrderClient has annotations [FeignClient] that are not used by contract Default
```

原因：

- 该旧开关会触发旧的 Feign Sentinel Builder
- 在当前 Boot 3 + Spring Cloud OpenFeign 组合下，会让 Feign 没走 Spring MVC Contract
- `@GetMapping`、`@PostMapping` 不能被正确识别

最终保留现代化方式：

```yaml
spring:
  cloud:
    openfeign:
      circuitbreaker:
        enabled: true
```

也就是说：Feign 熔断仍由 Sentinel CircuitBreaker 体系承接，但不再开启会破坏 Boot 3 OpenFeign 的旧开关。
