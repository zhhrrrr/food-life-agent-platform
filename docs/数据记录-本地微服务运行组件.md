## Nacos 配置

Nacos group：

```text
FOOD_LIFE_AGENT
```

Data ID：

```text
food-common.yaml
food-user-service.yaml
food-business-service.yaml
food-trade-service.yaml
food-gateway-service.yaml
```

启动脚本发布配置：

```powershell
.\scripts\publish-nacos-configs.ps1
```

校验配置：

```powershell
.\scripts\verify-nacos-configs.ps1
```

## 启动顺序

推荐一键启动基础设施：

```powershell
.\scripts\start-infra-all.ps1
```

启动业务服务和网关：

```powershell
.\scripts\start-local-services.ps1 -IncludeGateway -Restart
```

运行本地 smoke test：

```powershell
.\scripts\smoke-test-local-microservices.ps1
```

停止业务服务：

```powershell
.\scripts\stop-local-services.ps1
```

停止业务服务和基础设施：

```powershell
.\scripts\stop-local-services.ps1 -IncludeInfrastructure
```

## 已验证结果

- 基础设施端口检查通过。
- Nacos 配置发布与读取通过。
- 四个服务注册到 Nacos。
- Gateway 通过 Nacos 发现 user/business/trade 服务。
- Redis Token 登录通过。
- 普通下单通过 Gateway 调 trade-service，再经 Feign 调 business-service。
- 普通下单后 RabbitMQ 产生订单事件、库存事件和延迟关单消息。
- 公网库存写接口被 Gateway 返回 `403`。
- business-service 和 trade-service Actuator health 中 RabbitMQ、Nacos、Redis、DB、Sentinel 均为 `UP`。
- 四个服务 Prometheus 指标均可访问。
