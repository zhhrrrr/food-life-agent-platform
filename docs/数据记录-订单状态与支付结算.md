# 数据记录-订单状态与支付结算

## 关联数据库

```text
food_trade_db
```

## 关联表

```text
dining_order
dining_order_item
```

本阶段没有新增支付单表，支付成功结算先落在订单主表状态上。

## 订单状态

`dining_order.order_status` 当前包含：

```text
WAIT_PAY
订单已创建，等待支付。

PAID
订单已经完成支付成功结算。

CANCELED
订单已取消。
```

## 状态流转

```text
普通购买下单：null -> WAIT_PAY
模拟支付成功：WAIT_PAY -> PAID
取消订单：WAIT_PAY -> CANCELED
```

## 当前支付结算数据写入

当前模拟支付成功接口：

```text
POST /api/trade/orders/{orderId}/pay/mock
```

执行成功后更新：

```text
dining_order.order_status = PAID
dining_order.update_time = 当前时间
```

更新条件：

```text
id = orderId
order_status = WAIT_PAY
```

这个条件用于保证：

```text
重复支付不能成功
取消后不能支付
并发支付只有一次能成功
```
