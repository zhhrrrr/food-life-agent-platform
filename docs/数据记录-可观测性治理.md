## 三、Nacos 配置

公共配置：

```text
deploy/nacos/configs/food-common.yaml
```

核心内容：

```yaml
management:
  endpoints:
    web:
      exposure:
        include: health,info,prometheus,metrics
  endpoint:
    health:
      probes:
        enabled: true
      show-details: always
  health:
    rabbit:
      enabled: ${FOOD_RABBIT_HEALTH_ENABLED:false}
  metrics:
    tags:
      application: ${spring.application.name}
  tracing:
    sampling:
      probability: ${MANAGEMENT_TRACING_SAMPLING_PROBABILITY:1.0}

food:
  observability:
    enabled: ${FOOD_OBSERVABILITY_ENABLED:true}
    trace-header: ${FOOD_TRACE_HEADER:X-Trace-Id}
    request-log-enabled: ${FOOD_REQUEST_LOG_ENABLED:true}
    log-normal-request: ${FOOD_LOG_NORMAL_REQUEST:false}
    slow-api-threshold-ms: ${FOOD_SLOW_API_THRESHOLD_MS:1000}
    slow-feign-threshold-ms: ${FOOD_SLOW_FEIGN_THRESHOLD_MS:800}
```

Feign 熔断与观测：

```yaml
spring:
  cloud:
    openfeign:
      circuitbreaker:
        enabled: true
      micrometer:
        enabled: true

feign:
  sentinel:
    enabled: false
```

说明：

```text
Boot 3 使用 Spring Cloud OpenFeign CircuitBreaker 对接 Sentinel。
旧的 feign.sentinel.enabled 会让 Alibaba Sentinel Feign Builder 介入，在当前组合下容易退回 Feign 默认 Contract。
```

```text

deploy/nacos/configs/food-business-service.yaml
```

## 九、traceId 规则

请求头：

```text
X-Trace-Id
```

规则：

```text
1. 请求进来时，如果已有 X-Trace-Id，则继续沿用
2. 如果没有，则当前服务生成一个新的 traceId
3. traceId 写入 MDC
4. traceId 写回响应头
5. Feign 透传 authorization 和内部调用标识，traceId 由 Micrometer Tracing/OpenFeign 观测链路承接
```

## 十、慢接口规则

慢接口阈值：

```text
FOOD_SLOW_API_THRESHOLD_MS
默认 1000 ms
```

慢 Feign 阈值：

```text
FOOD_SLOW_FEIGN_THRESHOLD_MS
默认 800 ms
```

超过阈值后的行为：

```text
接口慢 -> warn 日志 + slow request counter
Feign 慢 -> warn 日志
```
