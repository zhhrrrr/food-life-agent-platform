# 数据记录-订单退款状态

## 关联数据库

```text
food_trade_db
```

## 关联表

```text
dining_order
```

## 新增订单状态

```text
REFUNDED
```

含义：

```text
订单已经完成模拟退款。
```

## 当前状态流转

```text
下单：null -> WAIT_PAY
取消：WAIT_PAY -> CANCELED
模拟支付：WAIT_PAY -> PAID
模拟退款：PAID -> REFUNDED
重复退款：REFUNDED -> REFUNDED，返回 repeat
```

## 模拟退款接口

```text
POST /api/trade/orders/{orderId}/refund/mock
```

当前执行成功后更新：

```text
dining_order.order_status = REFUNDED
dining_order.update_time = 当前时间
```

更新条件：

```text
id = orderId
order_status = PAID
```

这个条件用于保证：

```text
只有已支付订单可以退款
重复退款返回 repeat 行为
待支付订单不能退款，应该走取消订单
已取消订单不能退款
并发退款只有一次能成功
```
