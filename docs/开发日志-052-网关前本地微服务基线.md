# 开发日志-052-网关前本地微服务基线

## 1. 本次目标

本次不开发微服务网关，只补齐做网关之前需要稳定下来的本地微服务基线。

当前后端服务已经形成三个核心业务服务：

```text
food-user-service      用户、登录、关注、个人主页
food-business-service  店铺、套餐、评价、收藏、店铺主页聚合
food-trade-service     普通购买、拼团、秒杀、支付模拟、退款、核销、订单查询
```

为了后续接入 `food-gateway-service` 时减少环境混乱，本次新增本地启动、停止和冒烟验证脚本。

## 2. 新增脚本

启动本地三服务：

```powershell
.\scripts\start-local-services.ps1
```

重新打包并重启三服务：

```powershell
.\scripts\start-local-services.ps1 -Rebuild
```

停本地三服务：

```powershell
.\scripts\stop-local-services.ps1
```

网关前冒烟检查：

```powershell
.\scripts\smoke-before-gateway.ps1
```

携带登录 Token 做用户态冒烟检查：

```powershell
.\scripts\smoke-before-gateway.ps1 -Token "{token}"
```

## 3. 服务端口

| 服务 | 端口 | 健康检查 |
| --- | --- | --- |
| `food-user-service` | 8101 | `GET http://localhost:8101/health` |
| `food-business-service` | 8201 | `GET http://localhost:8201/health` |
| `food-trade-service` | 8301 | `GET http://localhost:8301/health` |

## 4. 脚本职责

`start-local-services.ps1`：

```text
1. 创建 logs 目录。
2. 可选停止旧进程。
3. 可选执行 Maven 打包。
4. 依次启动 user、business、trade 三个 jar。
5. 等待三个服务健康检查通过。
```

`stop-local-services.ps1`：

```text
按 8101、8201、8301 端口查找监听进程并停止。
```

`smoke-before-gateway.ps1`：

```text
1. 验证三个服务健康检查。
2. 验证公开店铺、分类、套餐交易快照接口。
3. 验证受保护业务接口无 token 返回 401。
4. 如果传入 Token，继续验证 /api/user/me、店铺主页、订单列表。
```

## 5. 和网关的边界

本次明确没有实现网关。

当前脚本仍然直接访问各服务端口：

```text
8101 user-service
8201 business-service
8301 trade-service
```

下一步做 `food-gateway-service` 时，才会把统一入口切到类似：

```text
8080 gateway
```

并由网关负责：

```text
统一路由
Token 透传
跨域
限流
统一入口路径
```

业务逻辑仍然留在各自微服务内。
