# 开发日志 033：普通订单链路查询与补偿消息查询

## 一、开发目标

本次继续只做非 Agent 业务。

普通购买已经具备库存销量闭环、补偿消息和幂等记录。本次补齐“排障查询能力”，让一笔普通订单可以一次看到：

```text
订单主表
订单明细
套餐交易快照
trade-service 库存同步消息
business-service 库存销量幂等记录
当前订单阶段
```

## 二、新增接口

### 1. 普通订单链路查询

```http
GET /api/trade/orders/{orderId}/normal-trace
```

返回内容：

```text
order
packageInfo
stockMessages
stockChangeRecords
currentStage
```

### 2. 普通库存消息查询

```http
GET /api/trade/normal/package-stock/messages?orderId=44
GET /api/trade/normal/package-stock/messages?messageStatus=FAILED
```

可按：

```text
orderId
messageStatus
limit
```

过滤。

### 3. business-service 幂等记录查询

```http
GET /api/package/stock-change-records?operationIdPrefix=NORMAL_PACKAGE&packageId=1&limit=20
```

trade-service 的普通订单 trace 通过 `IBusinessPackagePort` 调用该接口，不直接查询 business-service 数据库。
