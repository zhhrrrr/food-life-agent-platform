## 四、本次补齐后的关键规则

Gateway 认证白名单不再放开整个套餐域：

```text
/api/package/*
/api/package/of/shop
/api/package/trade-snapshot/*
```

Gateway 黑名单继续兜底拦截旧库存写路径：

```text
/api/package/*/stock/occupy
/api/package/*/stock/release
/api/package/*/sold/confirm
/api/package/*/sold/rollback
```

内部写接口统一走：

```text
/api/internal/**
```

并校验：

```text
x-internal-call
x-internal-secret
```

## 五、仍可继续增强的部分

这些不是当前阻断问题，但适合后续提升项目面试含金量：

1. 接入 Springdoc OpenAPI，把各微服务 API 文档统一到 Gateway。
2. 扩展 CI，把镜像构建、Nacos 配置校验和部署前检查纳入流水线。
3. 评估 Spring Boot 3.5.x 或 4.x 升级，但需要同步验证 Spring Cloud Alibaba、Sentinel、Seata 兼容性。
4. 增加容器化部署说明，把 MySQL、Redis、RabbitMQ、Nacos、Sentinel、Prometheus、Grafana 的启动顺序固化。
