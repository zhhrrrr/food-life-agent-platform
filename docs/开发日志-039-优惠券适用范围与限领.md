# 开发日志 039：优惠券适用范围与限领

## 一、开发目标

本次继续完善普通购买优惠券能力，把优惠券从“只要满金额就能用”升级为更接近真实生产业务的规则：

```text
优惠券可以限制适用范围
优惠券可以限制每个用户领取次数
用户券保存领取时的范围快照
普通购买下单时校验优惠券是否适用于当前套餐
```

本次仍然不新增单独的营销微服务，优惠券继续放在 `trade-service` 内部营销子域，符合当前“尽量减少服务数量”的拆分策略。

## 二、业务规则

### 1. 适用范围

新增三种范围：

```text
ALL      全平台可用
SHOP     指定店铺可用
PACKAGE  指定套餐可用
```

校验规则：

```text
ALL：不限制店铺和套餐
SHOP：user_coupon.scope_shop_id 必须等于套餐快照 shopId
PACKAGE：user_coupon.scope_package_id 必须等于套餐快照 packageId
```

当前本地默认券 `id=1` 调整为：

```text
scopeType = PACKAGE
scopePackageId = 1
```

也就是只允许套餐 1 使用。

### 2. 每人限领

模板新增：

```text
user_receive_limit
```

规则：

```text
user_receive_limit > 0：同一用户最多领取 N 张同一模板券
user_receive_limit <= 0：不限制领取次数
```

当前本地默认券 `id=1` 设置为每人限领 1 张。

### 3. 用户券范围快照

用户领取优惠券时，把模板范围复制到 `user_coupon`：

```text
scope_type
scope_shop_id
scope_package_id
```

原因：

```text
模板后续可能被运营调整
用户已领取的券应该保留领取时的适用范围
下单校验只依赖用户券快照，避免历史券规则漂移
```

## 四、接口验证

本地准备两个测试券模板：

```text
templateId = 901
scopeType = PACKAGE
scopePackageId = 1
userReceiveLimit = 1

templateId = 902
scopeType = PACKAGE
scopePackageId = 3
userReceiveLimit = 1
```

### 1. 模板列表返回范围字段

```http
GET /api/trade/coupons/templates?limit=20
```

返回包含：

```text
templateId = 901
scopeType = PACKAGE
scopePackageId = 1
userReceiveLimit = 1

templateId = 902
scopeType = PACKAGE
scopePackageId = 3
userReceiveLimit = 1
```

### 2. 领取并保存范围快照

```http
POST /api/trade/coupons/templates/901/receive
```

返回：

```text
userCouponId = 7
userId = 35
scopeType = PACKAGE
scopePackageId = 1
couponStatus = UNUSED
```

数据库确认：

```text
user_coupon.id = 7
template_id = 901
scope_type = PACKAGE
scope_package_id = 1
```

### 3. 重复领取被拦截

再次调用：

```http
POST /api/trade/coupons/templates/901/receive
```

返回：

```text
code = 400
message = coupon receive limit reached
```

### 4. 匹配套餐可以用券下单

使用 `userCouponId = 7` 下套餐 1：

```http
POST /api/trade/orders/normal
```

返回：

```text
orderId = 51
totalAmount = 16800
discountAmount = 1000
payAmount = 15800
userCouponId = 7
orderStatus = WAIT_PAY
```

数据库确认：

```text
user_coupon.id = 7
coupon_status = USED
used_order_id = 51
```

### 5. 不匹配套餐不能用券下单

使用 `templateId = 902` 领取的 `userCouponId = 8` 下套餐 1：

```http
POST /api/trade/orders/normal
```

返回：

```text
code = 400
message = coupon scope not matched
```

数据库确认：

```text
user_coupon.id = 8
coupon_status = UNUSED
used_order_id = NULL
```
